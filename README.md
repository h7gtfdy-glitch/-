# -# بوت قص خلفية الفيديو (تليجرام)

بوت يستقبل فيديو، يقص الخلفية تلقائياً (نموذج مخصص للأنمي: `isnet-anime`)،
ويركّب خلفية جديدة تختارها بالأزرار (أخضر / أزرق / أسود / أبيض / شفافة تجريبي).

## القيود المهمة
- تليجرام يسمح للبوتات بتحميل ملفات المستخدمين **بحد أقصى 20 ميجا**.
- افتراضياً الفيديو المسموح أطول شي **25 ثانية** (`MAX_DURATION_SEC`) — تقدر تزودها
  لكن انتبه لحدود الرام على الاستضافة المجانية (512 ميجا).
- خيار "شفافة" يطلع WebM بقناة ألفا تجريبية — أغلب التطبيقات (وتليجرام نفسه)
  ما تعرض الشفافية صح؛ الأفضل استخدام خيار "أخضر" وتطبيق Chroma Key بتطبيق
  مونتاج مثل Alight Motion.

---

## الخطوة 1: احصل على توكن البوت
1. افتح تليجرام وابحث عن `@BotFather`.
2. أرسل `/newbot` واتبع التعليمات (اسم البوت + username ينتهي بـ bot).
3. راح يعطيك **توكن** شكله شبيه `123456789:AAF...` — احفظه، بتحتاجه بالخطوة 3.

## الخطوة 2: ارفع هالملفات على GitHub
1. سوّي مستودع (repository) جديد على GitHub.
2. ارفع فيه الملفات: `bot.py`, `requirements.txt`, `Dockerfile`.

## الخطوة 3: انشر على Render (مجاني)
1. سوّي حساب على [render.com](https://render.com) (تقدر تسجل بحساب GitHub مباشرة).
2. من لوحة التحكم: **New +** → **Web Service**.
3. اربط مستودع GitHub اللي رفعت فيه الملفات.
4. Render بيكتشف الـ `Dockerfile` تلقائياً ويختار **Environment: Docker** — سيبها كذا.
5. اختر **Instance Type: Free**.
6. تحت **Environment Variables** ضيف:
   - `BOT_TOKEN` = التوكن اللي جبته من BotFather
   - (اختياري) `MAX_DURATION_SEC`, `MAX_WIDTH`, `TARGET_FPS` لو تبي تغيّر الحدود
7. اضغط **Create Web Service**. أول عملية بناء بتاخذ كذا دقيقة (تثبيت ffmpeg + المكتبات).

## ملاحظات عن الخطة المجانية
- الخدمة **تنام بعد 15 دقيقة بدون استخدام**، وأول رسالة بعد النوم بتاخذ
  حوالي 30-50 ثانية عشان "تصحى" — هذا طبيعي بالمجاني.
- عندك 750 ساعة تشغيل مجانية بالشهر، أكثر من كافية لبوت شخصي.
- أول فيديو ترسله بعد كل نشر جديد بياخذ وقت إضافي لأن نموذج `isnet-anime`
  (حوالي 170-200 ميجا) لازم ينزل من الإنترنت أول مرة.

## التشغيل محلياً (اختياري، للتجربة قبل النشر)
```bash
docker build -t bg-bot .
docker run -e BOT_TOKEN=توكنك -p 10000:10000 bg-bot
```

## تعديل الحدود
كل الإعدادات قابلة للتغيير بمتغيرات بيئة بدون لمس الكود:
| المتغير | الافتراضي | الوصف |
|---|---|---|
| `MAX_DURATION_SEC` | 25 | أقصى مدة فيديو مسموحة (ثواني) |
| `MAX_WIDTH` | 640 | أقصى عرض للفيديو الناتج (لتخفيف الحمل) |
| `TARGET_FPS` | 15 | عدد الفريمات بالثانية أثناء المعالجة |
| `REMBG_MODEL` | isnet-anime | نموذج القص (تقدر تغيّره لـ `u2net` أو غيره) |
